# 桌面端（Qt）设计语言

桌面端界面的取值与规则。改界面之前先读这里。数值只有一个来源：`desktop/src/Tokens.h`（尺寸、间距、圆角、字号）和 `desktop/src/Theme.cpp`（两套色板与 QSS）；本文只写用途和理由，不抄数值。实际效果用 `hov-qt --ui-gallery` 看，那一页渲染每个组件的每种状态。

## 定位

这是一个播放器：用户来找一个视频或一首歌，然后看或听。界面是内容的外壳，所以封面、画面和「正在播放」比控件醒目；控件数量少、尺寸统一、状态一眼可辨。

- 与 Android 端共用主色色相和 Material 3 的组件形态（胶囊按钮、筛选芯片、色阶分层），两端看起来是同一个 App。
- 不照搬 macOS 端顶栏的一排文字按钮：按钮一多就挤，文字按钮还会和搜索框抢注意力。低频操作收进「更多」菜单。
- 不用瀑布流：卡片高度不一，各列上下缘对不齐（维护者 2026-10-18 截图指出）。结果区是等高网格。

## 色彩

一个主色（Primary，蓝），两个状态色（Error、Success），其余全是中性色。

- 状态色只出现在下载面板：状态文字和进度条。其他地方出现红或绿就是错误。
- 视频区永远是 Scrim（黑），上面的文字和图标用 OnScrim，不随明暗切换。
- 选中状态用 PrimaryContainer 底配 OnPrimaryContainer 字，不用实心 Primary：一排芯片里出现实心色块会比内容还抢眼。实心 Primary 只给每个界面唯一的主操作和播放键。

### token 用途

| Tok | 用途 |
|---|---|
| `Surface` | 主窗口底色 |
| `SurfaceLow` | 面板（结果区、播放条）、对话框底色 |
| `SurfaceContainer` | 面板里的卡片、输入框、下拉框、次要按钮、菜单 |
| `SurfaceHigh` | 悬停 |
| `SurfaceHighest` | 按下；滑块与进度条的轨道；缩略图占位 |
| `OnSurface` | 正文、标题 |
| `OnSurfaceVariant` | 次要信息：时间、来源、状态、占位文字、默认图标 |
| `Outline` | 输入框悬停边框、未勾选的复选框与单选框 |
| `OutlineVariant` | 面板、输入框、芯片的常态边框；滚动条 |
| `Primary` | 主操作、播放键、滑块、进度、焦点边框、文字按钮的字 |
| `OnPrimary` | Primary 上的字与图标 |
| `PrimaryContainer` | 选中与开启状态的底色 |
| `OnPrimaryContainer` | PrimaryContainer 上的字与图标；主按钮悬停底色 |
| `Error` | 只用于下载失败 |
| `Success` | 只用于下载完成 |
| `Scrim` | 视频区底色 |
| `OnScrim` | 视频区上的空状态文字与图标 |

### 深色与浅色

两套色板在 `Theme.cpp` 的 `kDark` 与 `kLight`，按 `Tok` 的顺序一一对应，`static_assert` 保证条目数一致。`scripts/check-ui.py` 按 WCAG 公式验算关键配对：文字 4.5:1，控件边界和图形 3:1。

旧版深色「糊成一团」有两个原因：相邻两层底色只差 1.04:1，边框对底色只有 1.23:1。新色板层与层之间是 1.08–1.17:1，面板和输入框另有 OutlineVariant 边框，靠两种手段同时区分层次。

主题跟随系统（`ui.theme=auto`，经 XDG Portal），系统切换明暗时界面立即重绘：图标颜色在绘制时按当前色板取，不缓存。

## 字体

字体族依次取 Noto Sans CJK SC、Source Han Sans SC、PingFang SC、Noto Sans。只有三级字号：

| token | 用在哪里 |
|---|---|
| `fontTitle` | 对话框分组标题、面板标题、播放条里的曲名 |
| `fontBody` | 正文、按钮、输入框、卡片标题 |
| `fontCaption` | 时间、来源、状态、表头、卡片元信息 |

字幕与歌词画在视频上，字号随画面高度缩放（`SubtitleOverlay.cpp`），不受这三级约束。

## 尺寸

| token | 用在哪里 |
|---|---|
| `controlH` | 按钮、输入框、下拉框、数字框、标准图标按钮 |
| `controlSmallH` | 筛选芯片、表格行内的小图标按钮、复选框与单选框的行高 |
| `controlLargeH` | 只给播放/暂停 |
| `iconSmall` | 带文字的按钮、菜单、输入框里的图标、小图标按钮 |
| `iconStandard` | 标准图标按钮 |
| `iconLarge` | 播放/暂停 |
| `iconHero` | 空状态插图 |

同一行里的控件高度必须相同。播放键是唯一更大的控件，因为它是播放条的视觉中心。

## 间距、对齐与分隔

间距取 4 的倍数，只用五档：

| token | 用在哪里 |
|---|---|
| `space1` | 紧挨的元素：菜单内边距、进度条与文字之间 |
| `space2` | 同一行的相邻控件、卡片内边距、卡片之间 |
| `space3` | 区块之间（搜索行、芯片行、结果区、播放条）、分组之间 |
| `space4` | 主窗口外边距、播放条内边距 |
| `space6` | 对话框与独立面板的内边距、对话框底部按钮行上方 |

- 对齐：主窗口的搜索行、芯片行、结果区与视频区、播放条共用同一条左右边线，即窗口外边距。结果面板的内边距加卡片内边距等于播放条的内边距，所以卡片缩略图的左缘和播放条曲名的左缘在同一条线上。
- 对话框底部按钮右对齐：退出类按钮在左，主按钮在最右，右缘与上方输入框的右缘对齐。
- 分隔靠色阶加 1px OutlineVariant 边框，不用阴影：QSS 不支持 box-shadow，两套分组信号也会互相打架。

## 圆角

| token | 用在哪里 |
|---|---|
| `radiusXs` | 复选框、进度条 |
| `radiusSm` | 缩略图、菜单与菜单项、提示框 |
| `radiusMd` | 结果卡片、列表、表格 |
| `radiusLg` | 面板、对话框里的分组 |
| 胶囊（高度的一半） | 所有按钮、输入框、下拉框、芯片 |

视频区保持直角：画面由 OpenGL 绘制，做圆角要另外裁剪 framebuffer，代价与风险都不值得。

## 组件

页面代码只通过 `desktop/src/Ui.h` 建控件。组件在 QSS 里按 `hov` 属性匹配，尺寸由工厂函数固定。新增组件先加进 `Ui.h` 和陈列页，再在页面里用。

| 角色 | 函数 | 什么时候用 |
|---|---|---|
| 主操作 | `Ui::filledButton` | 每个界面最多一个：搜索、应用过滤器、保存、保存登录态 |
| 次要操作 | `Ui::tonalButton` | 面板里的批量动作、浏览… |
| 退出类操作 | `Ui::textButton` | 取消、关闭 |
| 图标按钮 | `Ui::iconButton` | 意义明确的单一动作；`tooltip` 同时是无障碍名称；可勾选时选中态自动换实心图标 |
| 播放/暂停 | `Ui::playButton` | 只在播放条 |
| 筛选芯片 | `Ui::chip` | 单选的来源切换，放进互斥的 `QButtonGroup` |
| 搜索框 | `Ui::searchField` | 顶部搜索 |
| 下拉框 | `Ui::asSelect` | 给已有的 `QComboBox` 统一高度与外观 |
| 面板 | `Ui::panel` | 结果区、播放条、对话框里的分组 |
| 文字 | `Ui::label` / `Ui::setTextRole` | Title、Body、Caption、CaptionVariant、OnScrim 五种 |
| 菜单项 | `Ui::menuAction` | 每个菜单项都带图标 |
| 进度条 | `Ui::progressBar` / `Ui::setProgressState` | 细条，不显示文字；数值放在旁边的列或提示里 |

复选框和单选框用原生 `QCheckBox` / `QRadioButton`，指示器由 `Ui.cpp` 的 `HovStyle` 绘制。下拉框、数字框的箭头在套用主题时渲染成 PNG 供 QSS 引用，因为 QSS 的 `image:` 只认文件。

## 图标

- 唯一的图标集：Material Symbols Rounded，固定上游提交，两份静态子集（线条与实心），来源与重新生成方法见 `desktop/resources/icons/README.md`。
- 名称登记在 `desktop/resources/icons/icons.txt`，生成的 `IconId` 枚举就是全集；写错名称时生成脚本失败，代码里写了不存在的 `IconId` 时编译失败。
- 默认用线条图标，实心只表示选中或开启。
- 不用品牌 logo：来源芯片用中性图标加文字，平台名靠文字识别。

## 文字

- 界面文字用简体中文，句子短，按钮用动词：搜索、保存、关闭、重试失败。
- 不用 emoji，也不用 ✓ ✗ 之类字符做装饰或状态。状态靠图标、颜色角色和文字一起表达，不单靠颜色。
- 长文本省略而不是硬截：卡片标题最多两行，末行加省略号；播放条曲名单行省略，完整标题放在悬停提示里。

## 刻意不做的

| 不做 | 原因 | 谁来拦 |
|---|---|---|
| 瀑布流错落卡片 | 列的上下缘对不齐 | 评审截图 |
| 阴影、渐变 | QSS 无阴影；两套分组信号互相打架 | 评审 |
| 玻璃质感作为默认 | 半透明降低对比度。`ui.glassWindow` 保留为可选项，只在深色生效，不再扩展 | 评审 |
| 字符或 emoji 当图标、QPainter 手绘图标 | 外观取决于字体，无上游可对照 | `check-ui.py` 的 `glyph` 规则 |
| 第二个强调色、品牌色 | 多个焦点互相竞争 | `check-ui.py` 的 `color` 规则 |
| 控件级 `setStyleSheet`、颜色字面量 | 绕开 token，换主题时失效 | `check-ui.py` 的 `stylesheet` 与 `color` 规则 |
| 写死的尺寸、间距、字号 | 尺寸与间距漂移，同一行高度不一 | `check-ui.py` 的 `size`、`spacing`、`font` 规则 |
| 页面代码直接 `new QPushButton` | 绕过组件库 | `check-ui.py` 的 `button` 规则 |
| 动效 | 播放器里长时间停留，动画只会分心；只保留 Qt 默认的悬停与按下反馈 | 评审 |
| 视频区圆角 | 见「圆角」 | 评审 |

## 检查

- `python3 scripts/check-ui.py`：上表的机器规则，外加色板对比度验算；CI 的「审核脚本」一步执行它。豁免的文件与理由用 `--list` 列出：token 与组件库本身；画在视频画面上的内容（字幕、歌词、封面卡、压暗层），因为它们不随界面主题变化；自测里的断言数值。
- `hov-qt --ui-gallery`：组件陈列页。改组件后先看这一页的深色和浅色。
- `hov-qt --grab <前缀> [--grab-after 秒] [--grab-size 宽x高]`：把所有可见窗口存成 PNG 后退出，用于截图评审。用 `HOME=<临时目录>` 隔离设置，不碰真实配置。
- 只能人看的：主次是否清楚、对齐是否成立、两种主题下是否都不糊。由维护者评审截图。
