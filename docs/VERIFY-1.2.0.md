## 一、macOS（DMG）

**安装**：打开 DMG → 拖入「应用程序」→ 首次启动如被拦截，在「系统设置 → 隐私与安全性」点「仍要打开」。

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 设置里选 1080p，再打开任意在线视频 | 控制条清晰度显示 **1080p**（修前会显示 480p —— 档位表错位） |
| 2 | 打开一个**本地**视频，把进度条拖到中段，反复拖几次 | **不冻结、不错位**（修前会冻几秒 —— 网络大缓存误作用于本地文件） |
| 3 | 播放一首音乐 → 点下载；或播放一个视频 → 点下载 | **音乐**：有声 + 封面 + 同名 `.lrc` 歌词文件；**视频**：**有声**（修前视频下载无声 —— 音轨是独立一路） |
| 4 | 控制条模式按钮点四下 | 顺序播放 → 单曲循环 → 随机播放 → 列表循环 → 回到顺序（图标随之变化） |
| 5 | 列表循环下让最后一首播完 | **自动回到第一首**继续；顺序播放模式播完最后一首则**停止** |
| 6 | 单曲循环下点「下一首」 | **能切到下一首**（手动切歌不受单曲限制） |
| 7 | 音乐界面 | 封面圆角 + 主题色磨砂 + 歌词渐隐渐显；有逐字歌词的曲目走 YRC 逐字高亮 |
| 8 | 全屏（双击画面/按钮） | 控制条两排、四角圆角、不裁切（如开启"铺满"则裁切填满） |
| 9 | 设置面板改一项 → 保存 | 有醒目保存提示；重启后设置仍在 |
| 10 | 搜索一个关键词 → 换来源再搜 | 每个来源**各自记住**上次关键词，列表与分页正确重建 |

**顺手看一眼日志**：`~/.config/hov/app.log` 里若出现 `[WATCHDOG] 主线程卡顿 N 秒`，把那几行连同截图发我。

## 四、已知限制（如实说明，不用当 bug 报）

- **Linux Flatpak 未做**：需要下载 ~1GB 运行时，当前以 AppImage + Arch 包交付。
- **YouTube 字幕 429 / VM 内 B 站 412**：是 IP 级限流/机房 IP 风控，本地网络通常正常。
- **QQ 音乐 VIP 曲目**：匿名返回 104003，需登录后解锁。
- **PGO 优化收益有限**（启动 −3.4% / 体积 −7.5%）：热点在 libmpv/Qt/ffmpeg 等外部库，属结构性原因。

## 五、发现问题怎么反馈给我

1. **一张截图**（界面问题必有）+ 一句话描述操作路径；
2. macOS/Linux 附 `~/.config/hov/app.log` 相关片段（尤其 `[WATCHDOG]`、`[SEEK]`、`[MUX]`、`[DL]`、`[SNAPSHOT]` 行）；
3. Android 附 `adb logcat -d | grep hov` 片段（如方便）；
4. 我会先定位**全链路**再改，避免引入新 bug。
